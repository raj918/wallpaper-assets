======================================================================
     ANIMEWALL 4K - DEDICATED ANIME WALLPAPERS INTEGRATION GUIDE
======================================================================

This guide explains how to fetch and consume ONLY Anime wallpapers in your
standalone Anime Wallpaper application (e.g., AnimeWall 4K), including the
dedicated Anime Sub-Categories system (All, Gojo, Naruto, etc.).

Both the main app catalog (wallpapers.json for Vexawall) and this anime catalog 
(anime_wallpapers.json & anime_categories.json for AnimeWall) are automatically
regenerated and synchronized together whenever you upload, transfer, delete, or
push from the Wallpaper Assets backend.


----------------------------------------------------------------------
1. WORKSPACE SELECTOR & DUAL ADMIN STUDIO
----------------------------------------------------------------------

When you launch the server (`npm start` at http://localhost:3000), you will see
a prominent 2-button Workspace Selector:

  ┌────────────────────────────────────────────────────────┐
  │         🚀 SELECT WALLPAPER STUDIO WORKSPACE           │
  │                                                        │
  │  [🌸 AnimeWall Studio]        [🖼️ Vexawall Studio]     │
  │   (Anime-Only App Backend)     (Master 16-Category)    │
  └────────────────────────────────────────────────────────┘

1. 🌸 AnimeWall Studio (Dedicated Anime Backend):
   • Manage anime-specific sub-categories (All, Gojo, Naruto, Solo Leveling...).
   • "All Wallpapers" contains ALL 159+ anime wallpapers.
   • Multi-tick checkboxes on every card: select multiple wallpapers and click
     "Transfer to Category" to organize them into sub-categories!
   • Upload new wallpapers directly into any anime category.
   • When you push to GitHub, both AnimeWall and Vexawall catalogs push together!

2. 🖼️ Vexawall Studio (Main Master App):
   • Full 16-category master catalog (Abstract, AMOLED, Cars, Anime, Nature...).
   • For Vexawall, ALL anime wallpapers belong directly to the single `Anime`
     category without sub-categories (zero breaking changes for Vexawall).
   • Top header switcher pill allows toggling between studios at any time!

3. THUMBNAILS (520px) VS FULL 4K RESOLUTION
----------------------------------------------------------------------

1. FAST GRID / STAGGERED FEED / CAROUSEL:
   Use: item.thumb
   • Scaled with Sharp to 520px width (retina mobile screen density)
   • Preserved chroma subsampling 4:4:4
   • Small file size (typically 40KB - 90KB) for instant 120Hz smooth scrolling.
   Example:
   https://raw.githubusercontent.com/raj918/wallpaper-assets/main/images/Anime_thumb/anime_1.jpg

2. FULLSCREEN PREVIEW / APPLY WALLPAPER / HIGH RES DOWNLOAD:
   Use: item.url
   • 100% original untouched 4K/UHD image file with zero recompression.
   Example:
   https://raw.githubusercontent.com/raj918/wallpaper-assets/main/images/Anime/anime_1.jpg


----------------------------------------------------------------------
4. MULTI-TICK TRANSFER & DUAL PUSH AUTOMATION
----------------------------------------------------------------------

1. TRANSFERRING WALLPAPERS INTO SUB-CATEGORIES:
   • In AnimeWall Studio, click the checkboxes on any wallpapers (or click "Select All").
   • Click "Transfer to Category (X)".
   • Select or create your category (e.g. "Gojo").
   • Click "Confirm Transfer".
   • Wallpapers are instantly organized into "Gojo", while still remaining inside
     the "All Wallpapers" master view.

2. ADDING NEW WALLPAPERS:
   • Uploading wallpapers from AnimeWall Studio saves them to `images/Anime/` and
     assigns them to your chosen anime category.
   • In Vexawall, they automatically appear in Vexawall's main `Anime` category!

3. 1-CLICK PUSH TO GITHUB:
   Whenever you click "Push to GitHub" from EITHER studio:
   • Both Vexawall catalogs (`wallpapers.json`, `categories.json`, `version.json`)
   • Both AnimeWall catalogs (`anime_wallpapers.json`, `anime_categories.json`, `anime_version.json`)
   are committed and pushed to GitHub together in a single atomic commit!

// 1. Data Models
data class AnimeCategoryItem(
    val name: String,
    val index: Int,
    val count: Int,
    val coverThumbnail: String?,
    val coverWallpaper: String?
)

data class AnimeCategoriesResponse(
    val version: Int,
    val categories: List<AnimeCategoryItem>
)

data class AnimeWallpaperItem(
    val id: String,
    val filename: String,
    val category: String,
    val animeCategory: String? = "All", // "All", "Gojo", "Naruto"...
    val name: String?,
    val title: String?,
    val index: Int,
    val isCover: Boolean = false,
    val url: String,
    val thumb: String
)

data class AnimeVersionResponse(
    val version: Int,
    val totalWallpapers: Int,
    val categoriesCount: Int,
    val category: String,
    val coverThumbnail: String?,
    val coverWallpaper: String?,
    val lastUpdated: String
)

// 2. Retrofit API Service
import retrofit2.http.GET
import retrofit2.http.Query

interface AnimeApiService {
    // Base URL: https://cdn.jsdelivr.net/gh/raj918/wallpaper-assets@main/data/
    
    @GET("anime_categories.json")
    suspend fun getCategories(
        @Query("t") timestamp: Long = System.currentTimeMillis()
    ): AnimeCategoriesResponse

    @GET("anime_wallpapers.json")
    suspend fun getWallpapers(
        @Query("t") timestamp: Long = System.currentTimeMillis()
    ): List<AnimeWallpaperItem>

    @GET("anime_version.json")
    suspend fun getVersion(
        @Query("t") timestamp: Long = System.currentTimeMillis()
    ): AnimeVersionResponse
}

// 3. Helper: Filter Wallpapers by Anime Category
fun List<AnimeWallpaperItem>.filterByCategory(categoryName: String): List<AnimeWallpaperItem> {
    if (categoryName.equals("All", ignoreCase = true)) {
        return this // "All" returns all anime wallpapers
    }
    return this.filter { it.animeCategory.equals(categoryName, ignoreCase = true) }
}
